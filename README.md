# 希土類デュアルユース・サプライチェーン監査

Y、Dy/Tb、Sm、Scについて、中国原料から国内の素材・部材、航空・宇宙・防衛用途までのつながりを、179社・事業単位と29サブカテゴリーから探索する静的な監査インターフェースです。HTML・CSS・JavaScriptで動作し、画面表示にビルドは不要です。

**[公開画面（index.html）を開く](https://weiwei1988.github.io/rare-earth-supply-chain-audit/)**

配布用HTMLそのものは [`index.html`](index.html) で確認できます。

## 使い方

公開画面をブラウザで開いてください。初期データは `index.html` に収録済みです。ローカルで使う場合はリポジトリを取得し、ルートディレクトリで静的HTTPサーバーを起動します。

```bash
git clone https://github.com/weiwei1988/rare-earth-supply-chain-audit.git
cd rare-earth-supply-chain-audit
python3 -m http.server 8000
```

その後、`http://localhost:8000/` を開きます。

- `Y`、`Dy・Tb`、`Sm`、`Sc`で表示対象の元素を絞り込めます。
- 工程またはサブカテゴリーを選ぶと、該当する企業・事業単位を一覧表示します。
- 企業カードを選ぶと、所有・上場、売上、製品、市場地位、航空・宇宙・防衛用途、中国依存、BOM根拠、追加DDギャップ、参照元を確認できます。
- 工程1では、元素別の中国依存度、指標の定義、データ品質、一次資料へのリンクを表示します。
- `Excelを読み込む`から対応する手元のExcelを一時的に反映できます。`初期データ`を押すと収録データへ戻ります。
- 狭い画面ではフロー図を横スクロールできます。明暗テーマにも対応します。
- 「全体」ではすべての接続線を表示し、サブカテゴリーを選ぶとその前後の直結線だけを表示します。
- 「防衛装備庁調達実績あり」は、人力更新シートに調達実績がある企業の表示です。詳細欄で工程5判定、対象品目、希土類判定を確認できます。
- 工程5は希土類フラグを持つ企業だけを表示します。「軍事用レーダー・モジュール」と「無人装備・ドローン」では、防衛装備庁の契約件名を文脈まで再確認した該当企業を表示します。

初期データの表示と操作に外部ライブラリの導入は不要です。Excel読込機能は外部CDNのSheetJSを利用するため、使用時のみネット接続が必要です。選択したExcelはブラウザ内で処理され、このリポジトリや外部サーバーへ保存する機能はありません。

## 収録範囲と注意点

5工程、29サブカテゴリー、179社・事業単位を収録しています。工程1の中国原料依存、工程2の分離・精製・金属・リサイクル・商流、工程3の素材・中間材、工程4の磁石・光学・電子・コーティング等、工程5の航空・宇宙・防衛用途を接続して表示します。工程4から工程5は、上流サブカテゴリーと下流用途の関係を希土類別に定義した32本の接続だけを表示します。

企業名だけでなく、事業部、子会社、企業グループ、商流上の参考ノードを含みます。そのため、179件は法人179社を意味しません。画面内の評価や市場地位、売上、用途、供給依存は、調査・分析用スナップショットです。

希土類フラグは、公開された製品情報、用途、一般的な部材構成から判断した曝露可能性を含みます。企業または型式固有のBOM、実際の含有、調達国、供給量を保証するものではありません。防衛用途との接続も、公開された契約実績だけでなく、航空・宇宙・防衛へ転用可能な製品・技術の評価を含みます。

工程1のSm・Scには、通関統計上の元素別分離ができないため代理指標を含みます。円グラフの定義と品質表示を確認し、異なる元素の数値を同じ精度の実績値として比較しないでください。最新性、完全性、契約主体の名寄せ、数値、一次資料の更新状況は、重要な判断の前にリンク先の原資料で再確認してください。

調査用Excelと防衛装備庁の契約原票・全件抽出データは収録していません。2026-09-15のローカル更新には、人力判定シートから画面用に抽出した企業・対象品目・判定情報を含みます。この更新のGitHub Pagesへの公開は未実施です。

工程5の採否はシートのAA列に加え、AE列（希土類フラグ）とAF列（希土類利用可能性）のいずれにも「対象外」がなく、希土類タグがあることを条件とします。ユーザー理由はAB列、分類と対象品目はAC列、対象外品目はAD列、希土類はAE列に従います。さらに、契約件名がサブカテゴリーの装置本体または直接モジュールを示すかを文脈確認し、試験・校正・整備・訓練・標的・倉庫・防雷・光学LiDARなどの名称一致だけによる分類を除外します。既存の高純度化学研究所はユーザー確認済みのY・Scフラグを優先して維持します。新設した「軍事用レーダー・モジュール」「無人装備・ドローン」は、統合契約時系列の契約件名を人力確認した追加分類です。カテゴリーから希土類を自動継承しません。DyとTbは従来の画面表示に合わせてDy/Tbへまとめ、元の指定も詳細欄に保持します。

## 検証

Node.js 18以降で、生成物の同期、データ構造、元素フラグ、工程間接続をまとめて検証します。追加のnpmパッケージは不要です。

```bash
npm test
```

期待値は、企業・事業単位179件、サブカテゴリー29件、文脈再確認後の人力判定57社を収録、調達実績フラグ58社、工程5は130件でタグなし0件、軍事用レーダー・モジュール9社、無人装備・ドローン10社、シートの希土類指定と一致、工程4→5の元素別接続32本、全接続に判定根拠あり、iframeなし、生成物同期済み、接続線の重複なしです。高純度化学研究所のY・Scはユーザー確認を優先して保持します。

## 工程4→5の直接接続監査

接続は「両カテゴリーに同じ元素フラグがある」だけでは作らず、工程4の機能材が工程5の機器・コンポーネントへ直接入る用途を説明できる場合に限定します。画面の「全体」では全接続線を表示し、サブカテゴリーを選択すると前後の直結線だけを残します。工程4・5を選ぶと `srcNotes` の根拠が下段に表示されます。企業カードの元素タグは調達品目単位の人力判定であり、この経路判定とは別です。

| 工程4 | 残した直接接続 | 今回外した広すぎる接続 |
|---|---|---|
| 固体レーザー発振器（YAG） | 高出力レーザー、誘導・慣性・航法、衛星・宇宙機・ロケット | 軍事用レーダー・モジュール、無人装備・ドローン。航空機構造・整備への線は元データにも存在しない |
| 耐熱（TBC）／耐プラズマコーティング | 航空エンジン・ガスタービン、原子力・核燃料被覆材 | 防衛半導体・電子回路・通信、航空機構造・整備。RF・圧電・高温センサへの線は元データにも存在しない |
| 電解質・センサ基板 | SOFC／SOEC、RF・圧電・高温センサ（YとSc） | なし。ScSZの高温センサ接続を追加 |
| 磁石（焼結・ボンド） | 誘導・慣性・航法、衛星・宇宙機・ロケット、飛行制御・電動化、ロボティクス・精密、無人装備・ドローン | 軍事用レーダー・モジュール、航空機構造・整備 |
| 薄膜・スパッタリングターゲット | 誘導・慣性・航法、RF・圧電・高温センサ、防衛半導体・電子回路・通信、軍事用レーダー・モジュール | なし。レーダーのYIG系経路にYを追加 |
| SAMウェハ・テンプレート | 誘導・慣性・航法、衛星・宇宙機・ロケット、RF・圧電・高温センサ、防衛半導体・電子回路・通信、軍事用レーダー・モジュール | なし |
| 金属AM造形・加工 | 衛星・宇宙機・ロケット、航空機構造・整備 | 飛行制御・電動化、無人装備・ドローン |

技術根拠の代表例は、[NASAのYSZ遮熱皮膜とタービン](https://ntrs.nasa.gov/citations/19760025104)、[NASAのNd:YAG宇宙LiDAR](https://ntrs.nasa.gov/citations/20020081031)、[IEEEのScAlN RFフィルタ](https://ieeexplore.ieee.org/document/11554995/)、[米海軍資料のレーダー用YIG増幅器](https://www.secnav.navy.mil/fmc/fmb/Documents/16pres/WPN_Book.pdf)、[NASAのScalmalloy宇宙AM部品](https://ntrs.nasa.gov/citations/20210016065)です。原子力線はY₂O₃／YSZ皮膜の研究・製造工程用途に限定し、量産被覆管の主流材を意味しません。

## 更新時

企業や分類を変更する場合は、目的に応じて `src/data/*.json` を編集し、生成と検証を実行してください。

```bash
npm run build
npm test
```

画面のレイアウトや描画ロジックは、`index.html` とJSXの生成マーカー外を編集します。サブカテゴリーを追加・変更する場合は、対象元素と1工程上流の `src` 接続も更新してください。工程5では `src` の各上流IDに対応する `srcEls` の希土類も更新し、用途と関係のない共通元素を自動接続しないでください。未確認のBOM、調達国、防衛契約、企業関係を推測で確定しないでください。
