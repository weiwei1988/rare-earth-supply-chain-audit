# 希土類デュアルユース・サプライチェーン監査

日本企業を中心に、Y、Dy/Tb、Sm、Scのサプライチェーンと航空・宇宙・防衛用途への接続を可視化する静的インターフェースです。

## 公開画面

GitHub Pagesで `index.html` を公開します。元素フィルター、工程別カード、企業詳細、出典表示をブラウザ上で操作できます。

## 構成

- `index.html` — iframeを使わない配布用画面
- `src/希土類サプライチェーン.jsx` — JSXソーススナップショット
- `scripts/qa.mjs` — 静的QA
- `scripts/audit.mjs` — グラフ接続監査
- `data/` — DD・調達実績のExcel成果物

## 検証

Node.js 18以降で次を実行します。

```bash
npm test
```

検証対象には、企業数123件、名称重複、iframe不在、日本アビオニクスの元素フラグ、工程5「ロボティクス・精密」のSmフラグ、接続線の重複・空端点除去などが含まれます。

## データ利用上の注意

Excel成果物は公開情報に基づく調査・分析用スナップショットです。希土類利用可能性は、調達品目と一般的な製品構成からの評価を含み、企業・型式固有のBOMを保証するものではありません。最新性・完全性・契約主体の名寄せ結果は、原資料でも再確認してください。
